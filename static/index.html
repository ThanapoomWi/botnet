เอกสาร API แบบกดทดลองได้อยู่ที่ /docs

MethodPathใช้ทำอะไร
GET/api/statusสถานะโมเดล threshold และน้ำหนัก
GET/api/metricsผลวัดบนชุด test และข้อมูลกราฟทั้งหมด
GET/api/catalogรายชื่ออุปกรณ์และชนิดทราฟฟิกในโฟลเดอร์ข้อมูล
GET/api/score/demo?device=1&attack=mirai.syn&n=200สุ่มจากชุด test แล้วตรวจ
GET/api/score/file?file_id=1:benign&n=500อ่านไฟล์ในโฟลเดอร์ข้อมูลแล้วตรวจ
POST/api/score/uploadอัปโหลด CSV (form field file)
POST/api/predictส่ง JSON {"rows": [{...115 features...}], "method": "Weighted"}
POST/api/reloadโหลดโมเดลใหม่หลังรัน train.py (ไม่ต้องรีสตาร์ตเซิร์ฟเวอร์)

curl -F "file=@Danmini_Doorbell/benign_traffic.csv" http://127.0.0.1:8000/api/score/upload

ระดับแจ้งเตือน

  • แจ้งเตือน — วิธีตัดสินที่เลือกบอกว่าโจมตี และโมเดลเดี่ยวเห็นด้วยอย่างน้อย 2 ใน 3
  • เฝ้าระวัง — ความเห็นไม่ตรงกัน: ตัวรวมผลบอกโจมตีแต่โมเดลเดี่ยวเห็นด้วยไม่ถึง 2 ตัว หรือตัวรวมผลบอกปกติแต่มีโมเดลเดี่ยวเตือน
  • ปกติ — ไม่มีโมเดลไหนเตือน
  • AE เท่านั้น — Autoencoder เตือนแต่ RF/XGB ไม่เตือน อาจเป็นรูปแบบการโจมตีที่ไม่เคยเห็นตอนฝึก
